QUESTION 1:
What is the primary function of the Global Search bar located in the ServiceNow Header Bar?
A) To search only records within the incident table.
B) To search terms across multiple active system tables, knowledge bases, and catalog items simultaneously.
C) To filter the table list in the data dictionary.
D) To execute real-time database query scripts.
CORRECT ANSWER: B
TECHNICAL RATIONALE: Global Search scans multiple indexed tables, knowledge articles, and catalog items from a single entry point in the header bar.
--------------------------------------------------------------------------------

QUESTION 2:
Which interface element in Next Experience allows users to save and organize frequently accessed links and pages?
A) Favorites (Star Icon / Favorites Tab)
B) History
C) Workspaces
D) Filter Navigator
CORRECT ANSWER: A
TECHNICAL RATIONALE: Favorites allow bookmarking modules, records, and reports using the star icon for instant access.
--------------------------------------------------------------------------------

QUESTION 3:
What happens when you type `<table_name>.list` into the Filter Navigator box?
A) Opens the list of records for that table in the current browser tab.
B) Opens the list of records for that table in a new browser tab/window.
C) Opens a new blank record form for that table.
D) Deletes all records in that table.
CORRECT ANSWER: A
TECHNICAL RATIONALE: The lowercase shortcut `.list` opens the record list in the current frame/tab, whereas uppercase `.LIST` opens it in a new window/tab.
--------------------------------------------------------------------------------

QUESTION 4:
Which shortcut typed in the Filter Navigator opens a blank form to CREATE a new record in a NEW browser tab?
A) `<table_name>.do`
B) `<table_name>.FORM`
C) `<table_name>.form`
D) `<table_name>.DO`
CORRECT ANSWER: D
TECHNICAL RATIONALE: The suffix `.do` opens a new record form in the current frame, whereas `.DO` opens the blank form in a new browser tab.
--------------------------------------------------------------------------------

QUESTION 5:
What does the Gear Icon located on the list header or form context menu represent?
A) Opens user personalization settings for columns and layout specific to the logged-in user.

C) Launches the JavaScript code editor.
D) Restarts the ServiceNow instance.

QUESTION 6:

QUESTION 7:
